工具概述

在 Windows System Kit (WSK) 环境中，ImageApp 和 UpdateApp 是构建和修改 Factory OS 映像的核心工具。它们位于 Windows ADK 的 Windows Kits\10\tools\bin\i386\ 目录下。

官方参考： ImageApp 和 UpdateApp 是 Windows ADK 中用于处理 FFU (Full Flash Update) 映像和包管理的底层工具。有关 Factory OS 工作区的更多信息，请参阅 Microsoft Learn — 工作区入门。
工具定位：
  • ImageApp： 底层映像构建引擎，负责从 OEMInput.xml 生成 FFU 映像，或向现有映像注入驱动/自定义内容。
  • ImgGen： ImageApp 的简化封装，适用于快速构建场景。
  • UpdateApp： 包管理工具，用于向已挂载的 VHD 映像安装、暂存或提交 CAB 包。

ImageApp — 映像构建与修补

必选参数： /CPUType 必须显式指定，可选值为 x86、ARM、ARM64、AMD64。

完整语法

imageapp OutputFile [OEMInputXML] [MSPackageRoot] [/MountAndInstall:x] [[+|-]StrictSettingPolicies] [[+|-]SkipImageCreation] [[+|-]RandomizeGptIDs] [[+|-]Recovery] [[+|-]ShowDebugMessages] /CPUType:x [/ChunkMappingFile:x] [/ScratchDir:x] [[+|-]Patch] [/Drivers:x] [/Customizations:x] [/TestContent:x] [/ ?]

参数说明

参数 说明
输出文件 要创建或修改的映像文件路径。（必填）
[OEMInputXML] OEM 输入 XML 文件的路径。默认值为空。
[MSPackageRoot] Microsoft 包文件根目录路径。仅在使用 OEMInputXML 时需要。默认值为空。
[/MountAndInstall] 要安装的内容列表（文件或目录），以分号分隔。会递归尝试安装内容。默认值为空。
[StrictSettingPolicies] 使没有策略的设置产生错误。使用 + 启用，- 禁用。默认 False。
[SkipImageCreation] 仅生成 OEM 自定义包，而不生成完整映像。使用 + 启用，- 禁用。默认 False。
[RandomizeGptIDs] 随机化 GPT 磁盘和分区 ID（用于并行运行 ImageApp）。使用 + 启用，- 禁用。默认 True。
[Recovery] 创建恢复 FFU 而非完整 FFU。使用 + 启用，- 禁用。默认 False。
[ShowDebugMessages] 显示额外的调试信息。使用 + 启用，- 禁用。默认 False。
/CPUType （必填） 指定目标 CPU 类型：x86、ARM、ARM64、AMD64。
[/ChunkMappingFile] （保留参数）默认值为空。
[/ScratchDir] 指定所有写入操作的临时文件夹路径。默认值为空。建议指定以避免 C 盘空间被占满。
[Patch] 用新内容修补现有映像，需要至少指定 /Drivers、/Customizations 或 /TestContent 中的一个。使用 + 启用，- 禁用。默认 False。
[/Drivers] 要修补到现有映像中的驱动程序文件夹路径。默认值为空。
[/Customizations] 要修补到现有映像中的自定义包文件夹路径。默认值为空。
[/TestContent] 要修补到现有映像中的测试内容文件夹（复制到 DATA\TestContent）。默认值为空。
[/?] 显示此帮助信息。

常用场景

A. 构建完整映像： 
imageapp C:\output.ffu C:\oem.xml C:\packages /CPUType:arm64

此命令会根据 oem.xml 和 packages 目录中的包，生成一个 ARM64 架构的 FFU 映像。

如需指定临时目录，可追加 /ScratchDir:C:\temp。

B. 驱动修补： 
imageapp C:\existing.ffu /CPUType:amd64 /Patch /Drivers:C:\drivers

将 C:\drivers 目录下的驱动注入到现有 FFU 映像中。

关于 /ScratchDir： 如果未指定 /ScratchDir，临时文件会写入系统盘（通常为 C 盘）。当构建大映像时，可能占用数十 GB 空间。建议始终指定到一个有足够空间的独立分区。在某些特定情况下构建失败可能无法卸载构建时产生的虚拟磁盘 ( 通常在具有存储池时会产生 ) 进而无法删除临时文件，这里需要读者自行寻找文件所在位置进行删除。

ImgGen — 简化构建工具

ImgGen 是 ImageApp 的简化封装，适用于快速构建 FFU 映像。语法更简洁，适合不需要复杂参数配置的场景。

语法

ImgGen OutputFile OEMInputXML MSPackageRoot [CPUType] Recovery
参数 说明
OutputFile 输出映像文件路径。（必填）
OEMInputXML OEM 输入 XML 文件路径。（必填）
MSPackageRoot Microsoft 包文件根目录路径。（必填）
[CPUType] 可选 CPU 类型覆盖：X86、AMD64、ARM 或 ARM64。
Recovery 可选参数，指定创建恢复 FFU 而非完整 FFU。
示例： 
ImgGen C:\output.ffu C:\oem.xml C:\packages ARM64

UpdateApp — 包管理与更新

UpdateApp 主要用于向已挂载的 VHD 映像添加 CAB 包，而无需重新构建整个 FFU。这对于快速迭代和测试非常有用。有关映像创建的更多信息，可参考 Microsoft Learn — 创建映像。

最常用命令

挂载并安装包： 
UpdateApp.exe mountandinstall <VHD路径> <CAB文件夹路径>

此命令会挂载 VHD，安装指定文件夹中的所有 CAB 包，然后卸载 VHD。

这适用于向已释放系统的 VHD 中额外添加驱动或功能包。

完整命令列表：

UpdateApp 支持丰富的子命令，包括分步操作（stage/commit/finalizecommit/rollback）、查询、功能管理、日志管理等。详细说明参见下方完整参数表。

完整参数列表

以下为 UpdateApp 所有子命令的简要说明：

命令 说明
install [finalize]将包列表安装到现有/已挂载的映像中（stage + commit）。
finalize 设置不可回滚点。
mountandinstall [finalize]挂载映像 → 执行 install → 卸载映像。最常用的命令。
stage [...]暂存包列表到映像中，之后需执行 commit 提交。
commit [noreboot] [finalize]提交先前暂存的更新。
noreboot 阻止自动重启。
finalizecommit执行最终提交操作，设置不可回滚点，升级池版本（如支持）。
rollback对具有待处理提交的映像执行回滚。
cleanup清理所有更新相关的文件。
renamepackages <folder>将 CAB 文件名重命名为 PackageName.cab。
getfeatures [pending] [product] [verbose]显示映像中所有已知功能。
getinstalledfeatures [pending] [product] [verbose]显示映像中已安装的功能。
getinstalledpackages显示映像中已安装的包。
installfeatures <ids>安装指定 ID 的功能。
uninstallfeatures <ids>卸载指定 ID 的功能。
getdeferredupdates [verbose]显示下次维护可应用的延迟更新。
dumpfilesystem将文件和目录转储到单个组件清单。
getservicingstatus获取当前维护状态。
getupdateresults获取上次提交的更新结果。
getfullupdateresults打印完整的更新结果信息。
reset [...]执行设备重置（如适用将重启设备）。
getdeviceinventory <folder>生成设备清单 XML。
logstorage记录所有空间和卷信息。
getlatestlogs <cab>将最新维护日志保存到 CAB 文件。
attachspaces根据覆盖/活动标志设置空间，使其与启动时状态匹配。
通配符支持： 任何包含包列表的选项都支持通配符模式。 
UpdateApp.exe mountandinstall C:\image.vhd C:\packages\
仅指定目录将包含该目录下的所有文件（非递归），等效于 C:\packages\ *。

最佳实践与注意事项

核心原则：
  • 使用同期的 ADK 工具： 构建时尽可能使用同一时期的 ADK 中的 ImageTools，以避免因不同时期的系统差距导致构建失败。
  • 指定 ScratchDir： 建议始终为 ImageApp 指定 /ScratchDir 参数，避免临时文件占满系统盘。
  • 备份现有映像： 使用 Patch 或 UpdateApp 修改现有映像前，请先备份原始文件。
  • 理解 finalize 的含义： 启用 finalize 后将无法回滚，在生产环境中谨慎使用。
