准备工作

重要提示： 必须将 qemu-system-ia64.EXE 放到 完整版本的 QEMU 安装目录（即包含 qemu-img.exe、qemu-system-x86_64.exe 等文件的目录）中运行，以避免因缺少依赖文件导致的运行错误。
⚠️ 兼容性警告： SKI 仿真器中已经启动到桌面的系统 不可直接迁移到 QEMU 运行，否则会导致系统启动崩溃。这是因为两种仿真器的硬件抽象层（HAL）和固件接口存在根本性差异。如需在 QEMU 中运行，请使用 QEMU 环境下的全新安装。
所需文件：
  • qemu-system-ia64.exe 下载
  • ia64-firmware.bin（IA64 UEFI 固件） 下载
  • 完整 QEMU 环境 — 建议使用官方 QEMU for Windows 包，将 qemu-system-ia64.EXE 放入其安装目录
  • 安装 ISO 镜像 — Windows Itanium 或 Linux IA64 的安装介质
  • NVRAM 文件 — 用于存储 UEFI 设置，如 nvram.bin（运行后自动生成）
目录结构示例： 
D:\QEMU\
├── qemu-system-ia64.EXE      ← 放入 QEMU 主目录
├── qemu-img.exe              ← 已有
├── qemu-system-x86_64.exe    ← 已有
├── UEFI\
│   └── ia64-firmware.bin
├── Disc01.iso
└── ia64.vhd

启动命令

IA64 模拟性能较低，启动可能需要较长时间，请耐心等待。
完整命令（分行便于查看参数）： 
D:\QEMU\qemu-system-ia64.EXE ^
    -machine ia64-vpc,i8042=off,nvram=nvram.bin ^
    -bios D:\QEMU\UEFI\ia64-firmware.bin ^
    -drive file="D:\Disc01.iso",media=cdrom,format=raw,readonly=on ^
    -accel tcg,thread=multi ^
    -smp 4 ^
    -m 4G ^
    -nic user,model=e1000 ^
    -drive file=D:\ia64.vhd,format=vpc ^
    -display gtk
简化版命令（便于复制）： 
qemu-system-ia64.EXE -machine ia64-vpc,i8042=off,nvram=nvram.bin -bios ia64-firmware.bin -drive file="install.iso",media=cdrom,format=raw,readonly=on -accel tcg,thread=multi -smp 4 -m 4G -nic user,model=e1000 -drive file=ia64.vhd,format=vpc -display gtk

参数说明

参数 值 说明
-machine ia64-vpc,i8042=off,nvram=nvram.bin 指定机器类型为 ia64-vpc，禁用 i8042 键盘控制器，指定 NVRAM 文件
-bios D:\QEMU\UEFI\ia64-firmware.bin 指定 IA64 UEFI 固件文件路径
-drive (CD-ROM) file="D:\Disc01.iso",media=cdrom,format=raw,readonly=on 挂载 ISO 镜像为虚拟光驱，只读
-accel tcg,thread=multi 使用 TCG 软件模拟，启用多线程加速
-smp 4 分配 4 个 CPU 核心（可根据实际调整）
-m 4G 分配 4GB 内存
-nic user,model=e1000 使用用户模式网络，模拟 Intel e1000 网卡
-drive (HDD) file=D:\ia64.vhd,format=vpc 挂载虚拟硬盘（VHD 格式）
-display gtk 使用 GTK 图形界面显示

虚拟磁盘创建

使用 QEMU 创建 VHD 格式磁盘： 
D:\>D:\QEMU\qemu-img.exe create -f vpc D:\ia64.vhd 20G
说明：
  • -f vpc — 指定 VHD 格式（Virtual PC 兼容）
  • D:\ia64.vhd — 磁盘文件路径
  • 20G — 磁盘大小（可根据需要调整）

注意事项

性能警告： TCG 软件模拟效率较低，IA64 模拟尤为明显。启动和安装过程可能需要较长时间，请耐心等待。
固件兼容性： 确保使用的 UEFI 固件与 QEMU 版本兼容。如遇到启动问题，尝试更换固件版本。
NVRAM 文件： NVRAM 文件用于存储 UEFI 设置。如启动异常，可删除并重新生成该文件。
网络配置： 使用 -nic user,model=e1000 可让虚拟机通过宿主机的网络访问外部网络。如需桥接网络，可改用 -nic tap,model=e1000。

故障排除

黑屏无法启动

尝试以下操作：

  • 检查 -bios 路径是否正确指向有效的 UEFI 固件
  • 删除 NVRAM 文件（nvram.bin）后重新启动
  • 尝试更换 -machine 参数，如 -machine virt
  • 确认 qemu-system-ia64.EXE 已放入完整 QEMU 目录
模拟速度极慢

优化建议：

  • 减少 -smp 核心数（如 2 核）
  • 减少 -m 内存分配（如 2G）
  • 确保宿主机有足够的 CPU 资源
无法从 ISO 引导

检查：

  • ISO 文件是否完整且可引导
  • 是否支持 IA64 架构
  • 尝试在 UEFI 固件中手动选择引导设备
