文档：在 WSL 中配置图形界面

为 WSL Ubuntu 安装中文图形界面支持 WSL Ubuntu ⚠️ Windows 10 专属
⚠️ 本教程仅在 Windows 10 中可用，其他 Windows 版本可能不兼容。

安装 WSL

命令： 在 Windows 中以管理员身份打开 PowerShell 或 CMD，运行以下命令： 
wsl --install -d <发行版名称>
说明： 建议使用 Ubuntu，例如 wsl --install -d Ubuntu。安装完成后启动 WSL，按照提示设置用户名和密码。

安装图形界面支持

适用环境： 本教程适用于 Windows 10 用户，默认在 root 用户下操作。
如果当前不是 root 用户，先执行：
wsl -u root -d Ubuntu
安装图形界面相关软件包：

执行以下命令安装 gedit 编辑器、中文输入法及中文字体：

apt update
apt install gedit fcitx fcitx-config-gtk fcitx-sunpinyin fcitx-pinyin fcitx-googlepinyin xfonts-intl-chinese
apt install xfonts-wqy xfonts-unifont fonts-wqy*
apt install language-pack-gnome-zh-hans language-pack-kde-zh-hans language-pack-zh-hans
软件包说明：
  • gedit — 图形化文本编辑器，用于测试界面是否正常工作
  • fcitx* — 中文输入法框架及多种输入法（拼音、双拼、谷歌拼音）
  • xfonts-* 和 fonts-wqy* — 中文字体支持
  • language-pack-* — 中文语言包

安装图形界面配置脚本

步骤 1：创建并进入工作目录 
mkdir /opt/WSL
cd /opt/WSL
步骤 2：克隆配置脚本

从 GitHub 获取 WSL 图形界面配置脚本：

git clone https://github.com/nufeng1999/wsl_XWin_Cygwin.git --recurse-submodules
说明： --recurse-submodules 参数会同时下载子模块，确保所有依赖完整。
步骤 3：执行安装脚本 
cd wsl_XWin_Cygwin
chmod +x ./install.sh
./install.sh
说明： chmod +x 赋予脚本执行权限，然后运行 install.sh 完成图形界面配置。

完成配置

重启 WSL

安装完成后，重启 WSL 即可正常使用图形界面。

在 Windows PowerShell 中执行：

wsl --shutdown
验证： 重新打开 WSL 终端，尝试运行 gedit 或 fcitx-config-gtk，验证图形界面是否正常工作。
