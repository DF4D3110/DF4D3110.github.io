使用说明
启动步骤：
  1. 下载对应 Build 的 ZIP 压缩包并解压到任意目录。
  2. 找到对应的启动脚本 ia64-xxxx.bat（如 ia64-4074.bat）。
  3. 直接双击运行，QEMU 将自动启动并进入系统桌面。
  4. 如需调整内存或 CPU 核心数，编辑 ia64-xxxx.bat，修改 -m 和 -smp 参数即可。
RDP 远程桌面：

启动脚本已默认开启 RDP 端口转发（宿主机端口 3389x → 虚拟机 3389）。启动后使用远程桌面连接 localhost:3389x 即可。

如宿主机已占用 3389x 端口，请修改脚本中的 hostfwd=tcp::3389x-:3389 为其他端口。

注意事项
各版本已知问题：
  • 5.1.2462.0： 需手动替换 ia64ldr.efi 和 npfs.sys 才能完成 GUI 安装（压缩包内已包含修复说明）。
  • Longhorn 系列（4033/4051/4067/4074）： 启动脚本已添加 -rtc base=2004-03-27 参数以绕过时间炸弹。
  • Itanium 1 镜像： 启动脚本使用 qemu-system-ia64-Itanium1.EXE 并已指定 -cpu merced，请勿修改。
性能提示：
  • TCG 软件模拟效率较低，建议关闭宿主机上其他占用 CPU 的大型程序。
  • 如运行卡顿，可尝试将 -smp 4 改为 -smp 1 以降低 CPU 负载。
  • Itanium 1 镜像建议内存不超过 1536M（脚本已默认配置）。
